# سیستم مدیریت خانه با STM32

یک سیستم چندحالته‌ی Embedded توسعه‌یافته با **STM32** که قابلیت‌های مختلفی از یک سیستم مدیریت محیط خانگی را شبیه‌سازی و پیاده‌سازی می‌کند.

این پروژه با هدف کار با چندین Peripheral و ترکیب آن‌ها در یک سیستم یکپارچه طراحی شده و شامل کنترل روشنایی، سیستم امنیتی، احراز هویت، دریافت اطلاعات آنالوگ، ارتباط سریال و پخش موسیقی است.

## ✨ قابلیت‌ها

### 💡 کنترل روشنایی

- کنترل چند LED با استفاده از کلیدهای فشاری
- تنظیم شدت نور LEDها با استفاده از PWM
- نمایش تعداد LEDهای فعال روی نمایشگر 7-Segment

### 🔐 سیستم امنیتی

- دریافت نام کاربری و رمز عبور از طریق UART
- احراز هویت کاربر
- تشخیص ورود غیرمجاز
- فعال‌سازی هشدار نوری و صوتی در هنگام ورود غیرمجاز
- نمایش پیام‌های وضعیت از طریق UART

### 📊 پایش ورودی آنالوگ

- دریافت اطلاعات از طریق ADC
- تعیین بازه‌ی زمانی نمونه‌برداری از طریق UART
- ارسال مقدار خوانده‌شده‌ی ADC از طریق UART

### 🎵 پخش موسیقی

- پخش ملودی با استفاده از Buzzer و PWM
- پشتیبانی از چند ملودی مختلف
- هماهنگ‌سازی LEDها با ریتم موسیقی
- امکان پخش مداوم یک ملودی برای مدت زمان مشخص

### 🔢 نمایشگر 7-Segment

- نمایش اعداد روی نمایشگر 7-Segment
- کنترل بخش‌ها و Digitهای نمایشگر با GPIO

## 📡 ارتباط UART

ارتباط UART برای تعامل با کاربر و تبادل اطلاعات با سیستم استفاده شده است.

از UART برای موارد زیر استفاده می‌شود:

- دریافت نام کاربری و رمز عبور
- دریافت تنظیمات اولیه‌ی سیستم
- تعیین پارامترهای زمانی
- ارسال مقادیر ADC
- نمایش پیام‌های امنیتی و وضعیت سیستم
- ارسال دستورات مربوط به حالت موسیقی
